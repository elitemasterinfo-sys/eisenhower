# ماتریس آیزنهاور

اپ تک‌فایلی (PWA، بدون فریم‌ورک) برای اولویت‌بندی کارها با ماتریس آیزنهاور، با سینک بین کامپیوترها و گوشی.

- **لینک برنامه:** https://elitemasterinfo-sys.github.io/eisenhower/
- **داده‌ها:** Firebase Realtime Database. دیتابیس قفل است و هر دستگاه یک بار «کد سینک» را می‌گیرد: با رمز واحد (پایین)، یا در تنظیمات، یا با QR از کامپیوتر.
- **راهنمای استفاده و راه‌اندازی:** [ONLINE_GUIDE.md](ONLINE_GUIDE.md)

> این ریپو و سایتش عمومی‌اند. هیچ رمز، توکن، کد سینک یا یادداشتی نباید در آن باشد.
> `.gitignore` فقط فایل‌های جدول پایین را راه می‌دهد؛ پوشه‌ی `backups/` فقط روی همین کامپیوتر می‌ماند.

## فایل‌ها

| فایل | کار |
| :--- | :--- |
| `index.html` | کل برنامه: ماتریس، یادداشت‌ها، سینک، سطل بازیافت، تنظیمات |
| `sw.js` | کش آفلاین: برنامه فوری باز می‌شود و بی‌اینترنت هم کار می‌کند |
| `manifest.json`، `icon-*.png` | نصب روی گوشی و دسکتاپ |
| `qrcode.js` | ساخت QR برای انتقال تنظیمات به گوشی (qrcode-generator از Kazuhiko Arase، مجوز MIT) |
| `fonts/` | فونت وزیرمتن، داخل خود برنامه (مجوز OFL) |
| `open.bat` | باز کردن برنامه روی کامپیوتر |
| `open_on_mobile_and_wifi.bat`، `tools/serve_lan.py` | اجرای برنامه روی شبکه‌ی وای‌فای همین کامپیوتر (فقط فایل‌های برنامه، نه `backups/`) |
| `tools/backup-firebase.ps1` | بکاپ روزانه‌ی فقط‌خواندنی از فایربیس در `backups/` (۳۰ تای آخر) |
| `tools/set-sync-code.bat` | گذاشتن کد سینک برای بکاپ روزانه و ساختن تسک زمان‌بندی‌شده |
| `vault.json` | کد سینک و تنظیمات تلگرام، قفل‌شده با رمز واحد (اگر ساخته شده باشد) |

## رمز واحد همه‌ی دستگاه‌ها

- روی هر دستگاه لینک برنامه را باز می‌کنی و رمز واحد را می‌زنی؛ برنامه باز می‌شود و سینک خودش روشن می‌شود. هر بار که مرورگر یا اپ از نو باز شود، رمز را دوباره می‌خواهد.
- `vault.json` کد سینک را با رمز قفل می‌کند (PBKDF2-SHA256 با ۶۰۰ هزار دور، بعد AES-GCM). خود کد هیچ‌جای ریپو نیست، ولی فایل قفل‌شده عمومی است؛ پس رمز باید بلند و حدس‌نزدنی باشد (دست‌کم ۱۲ کاراکتر).
- **ساختن یا عوض کردن رمز:** روی دستگاهی که همین الان سینک است، تنظیمات › امنیت › «ساخت رمز واحد». `vault.json` دانلود می‌شود؛ آن را کنار `index.html` بگذار و push کن. چند دقیقه بعد همه‌ی دستگاه‌ها رمز تازه را می‌خواهند.
- اگر کد سینک فایربیس عوض شد، رمز واحد را دوباره بساز.
- روی سرور وای‌فای (http) مرورگر رمزگشایی ندارد؛ آنجا همان رمز به‌عنوان رمز محلی دستگاه کار می‌کند.

## سینک چطور کار می‌کند

- هر دستگاه اول نسخه‌ی ابری را می‌خواند، با نسخه‌ی خودش **ادغام** می‌کند و فقط اگر چیزی اضافه شده بنویسد. نوشتن شرطی است (ETag): اگر دستگاه دیگری وسطش نوشته باشد، دوباره می‌خواند و ادغام می‌کند. هیچ دستگاهی کل لیست را روی بقیه نمی‌نویسد.
- **حذف یعنی رفتن به سطل بازیافت**، روی همه‌ی دستگاه‌ها. «خالی کردن سطل» فقط یک علامت بدون متن باقی می‌گذارد.
- اگر یک تسک در یک طرف نباشد، حذف حساب نمی‌شود و برمی‌گردد؛ پس دیتابیسِ پاک‌شده یا لیستِ قدیمی هیچ چیزی را از بین نمی‌برد.
- اگر دو دستگاه هم‌زمان یک تسک را عوض کنند، ویرایش جدیدتر می‌ماند و متن دیگر به سطل بازیافت می‌رود.
- آفلاین یا بی‌فیلترشکن: تغییرات روی دستگاه می‌مانند و با وصل شدن ادغام و ارسال می‌شوند. وضعیت و تعداد تغییرهای ارسال‌نشده بالای صفحه است.
- به‌روزرسانی زنده با اتصال SSE فایربیس؛ اگر اتصال بیفتد، هر ۱۵ ثانیه چک می‌شود.
- **تنظیمات هم سینک می‌شوند:** کلید Gemini، توکن ربات تلگرام، شناسه چت و روشن/خاموش تلگرام کنار تسک‌ها در `settings` دیتابیس می‌نشینند. روی هر دستگاه یک بار وارد کنی، بقیه موقع باز شدن برنامه، یا اگر باز است حدود یک دقیقه بعد، می‌گیرند. هر تنظیم زمان آخرین تغییرش را دارد و جدیدترین می‌ماند. کد سینک خودش آنجا نیست و از `vault.json` می‌آید.

لایه‌های پشتیبان: دیتابیس ابری، ۳۰ نسخه‌ی خودکار در هر مرورگر، فایل پشتیبان JSON از تنظیمات، بکاپ روزانه روی کامپیوتر، و (اگر فعال باشد) ربات تلگرام.

## قانون‌ها برای هر تغییری در کد

1. قبل از هر تغییری که به داده یا سینک مربوط است، یک بکاپ فقط‌خواندنی از فایربیس در `backups/` بگیر.
2. تست فقط روی کپی برنامه با یک دیتابیس آزمایشی محلی؛ هرگز PUT، PATCH یا DELETE روی دیتابیس اصلی برای تست.
3. تعداد تسک‌ها را قبل و بعد از هر تغییر با بکاپ تازه مقایسه کن.
4. رمز، توکن، کد سینک و یادداشت هرگز وارد گیت نمی‌شود (فقط `vault.json` که قفل‌شده است).
5. فایل‌های `.bat` فقط حروف انگلیسی (ASCII) داشته باشند: cmd در فایلی که `chcp 65001` و متن فارسی با هم دارد، خط‌ها را بی‌صدا جا می‌اندازد.
